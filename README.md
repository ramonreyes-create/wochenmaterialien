# Wochenmaterialien

Página semanal de materiales para la 11. Klasse.

- Muestra automáticamente la semana actual de lunes a viernes.
- Los materiales y archivos se guardan en este mismo repositorio.
- La web se publica con GitHub Pages.
- El modo de profesora usa un Fine-grained Personal Access Token limitado a este repositorio con permiso **Contents: Read and write**.

Sitio: https://ramonreyes-create.github.io/wochenmaterialien/
