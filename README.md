# Wochenmaterialien

Página semanal de materiales para la 11. Klasse.

- Muestra automáticamente la semana actual de lunes a viernes.
- Los materiales y archivos se guardan en este mismo repositorio.
- La web se publica con GitHub Pages.
- Las alumnas usan un código asignado para registrar cuándo abren o completan una actividad.
- Los registros se guardan de forma privada en Cloud Firestore, dentro del proyecto Firebase `deutschkurs-6e949`.
- Las alumnas solo pueden crear registros asociados a su sesión; no pueden leer, modificar ni borrar registros.
- El modo de profesora usa un Fine-grained Personal Access Token limitado a este repositorio con permiso **Contents: Read and write**.

Los registros se consultan desde **Firebase Console → Firestore Database → `activityLogs`**.
